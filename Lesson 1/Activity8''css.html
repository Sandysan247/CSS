Normal HTML Commands

Paragraph Tag

Used to write normal text content.

<p>This is a paragraph</p>
Heading Tag

Used to show headings from h1 to h6.

<h1>Heading</h1>
Bold Text

Makes text bold.

<b>Bold Text</b>
Italic Text

Makes text italic.

<i>Italic Text</i>

Special HTML Commands

Superscript

Displays power or exponent values.

a<sup>2</sup> → a²
Subscript

Used in chemical formulas.

CO<sub>2</sub> → CO₂
Mark Tag

Highlights important text.

<mark>Important</mark>
Code Tag

Displays programming code.

<code>print("Hello")</code>
